# Codex 助手包 · 安装说明（P4 / 1.0.x）

> **1.5.x 起请读 [`user-install-guide.md`](user-install-guide.md)。** 这一份是 P4（1.0.x）时期的说明，与现在的包有四处不同：
>
> 1. 向导多了一页「本产品为会话记录服务」，没有勾选框；
> 2. 任务记录不再是「可选、默认关闭」的开关——记录由独立的后台组件承担，随安装生效；
> 3. 安装会注册登录计划任务 `CodexCompanion\Collector`（本文第 7 节「不创建计划任务」已过期）；
> 4. 插件还提供 5 个 MCP 工具（`collector_status` / `pause` / `resume` / `stop` / `open_panel`）。

适用：Windows 10 / 11 上的**官方 Codex 桌面 App**（已验证 App 26.1013.4894.0，内核 0.163.0-alpha.10.2）。
不需要管理员权限，不需要另外安装 Python，不修改 Codex 程序文件。

## 1. 安装（一次）

1. 双击 **`CodexCompanion-Setup-<版本>.exe`**。
   - 如果 Windows 提示「Windows 已保护你的电脑 / 未知发布者」：点「更多信息」→「仍要运行」（安装包暂无代码签名，见已知限制）。
2. 按向导点「下一步」→「安装」。安装程序会：
   - 把文件放到 `%LOCALAPPDATA%\Programs\CodexCompanion`；
   - 备份 Codex 配置，然后用 **Codex 自带的命令**注册插件「Codex 助手包」；
   - 检查 Codex 版本（不兼容时会说明原因与仍可使用的功能，见第 6 节）；
   - 如果之前装过开发版插件（Codex Task Recorder / Codex CDK 充值），询问是否卸载它们（建议「是」，否则会重复记录、`/充值` 弹两个窗口）。
3. 完成页勾选「打开 Codex 助手包」→ 控制面板会列出还差哪几步。

## 2. 在 Codex 中启用（一次，必须由你亲自操作）

1. **完全退出**并重新打开 Codex 桌面 App（托盘里也要退出）。
2. 打开 **插件 → Codex 助手包**，点 **「全部信任」**。
   - 这是 Codex 的安全要求：插件的 Hook 必须由你亲自确认，安装程序不会、也不能代你确认。
   - 也可以在 设置 → Hooks 中逐个信任。
3. 回到控制面板（开始菜单「Codex 助手包」）点「重新检测」，「Hook 信任」应显示「已信任 12/12」。

## 3. 绑定账号并充值

1. 在任意对话的输入框**单独发送 `/充值`**（全角 `／充值` 也可以）。这条消息会被拦下，不会发给模型。
2. 弹出「Codex 充值」小窗口，显示当前 Codex 登录的 ChatGPT 账号 → 点「确认充值到此账号」（只需第一次）。
3. 输入 CDK → 「确认兑换」。CDK 只在这个小窗口里输入，不会进入 Codex 对话、日志或任何记录。
4. 也可以从开始菜单「Codex 助手包 → Codex 充值」直接打开窗口；充值窗口不需要一直开着。

## 4. 任务记录（可选，默认关闭）

1. 在 Codex 中发送 **`/记录`**，或从开始菜单打开「Codex 助手包」。
2. 点「开启任务记录」→ 阅读授权说明（记录并上传哪些内容、不采集哪些内容、上传到哪里）→「同意并开启」。
3. 之后正常使用 Codex 即可：每个会话第一条消息后会出现「● Codex 助手包正在记录本会话并上传（你已授权）…」。
4. 控制面板随时显示：是否在记录、待上传 / 已上传条数、最近上传时间、最近错误。

| 想要 | 怎么做 |
|---|---|
| 暂停 | 面板点「暂停任务记录」：立即停止记录与上传，尚未上传的内容留在本机 |
| 恢复 | 面板点「恢复任务记录」（不需要重新阅读说明） |
| 撤销授权 / 删除数据 | 面板点「撤销授权…」，可勾选「删除后台已上传的全部数据」「删除本机记录」 |
| 临时彻底关掉 | 在 Codex 插件页**禁用**「Codex 助手包」：记录与上传立即停止（充值的 `/充值` 也随之停用，可从开始菜单打开充值窗口） |

## 5. 更新

- 默认「提示我」：每天最多检查一次；有新版本时面板显示「更新到 x.y」，Codex 中每天最多提示一次。点击并确认后才会下载、校验并安装。
- 面板底部「更新方式」可改为「自动安装」（后台下载校验后静默安装；需要重新信任 Hook 的版本仍会先问你）或「不检查」。
- 更新不会改变你的授权、充值绑定与本机记录；通常不需要重新信任 Hook。你在 Codex 中禁用了插件时，更新后仍保持禁用。
- 自动安装不会在充值窗口开着时进行，也不会弹出窗口打断你。

## 6. Codex 版本不兼容时

安装程序和控制面板都会检查 Codex 版本：

| 情况 | 表现 |
|---|---|
| 已验证的版本 | 正常 |
| 比已验证的更新 | 提示「未经验证的版本」，照常工作；如遇问题可在面板暂停任务记录 |
| 低于最低版本，或缺少插件 Hooks 功能 | **降级运行**：停用插件（不记录、不上传、`/充值` 不可用），说明原因；仍可从开始菜单打开「Codex 充值」窗口充值。升级 Codex 后在面板点「重新检测」即恢复 |
| 未安装 Codex | 提示先安装并打开一次 Codex，再点「重新检测」 |

## 7. 卸载

- Windows「设置 → 应用 → 已安装的应用 → Codex 助手包 → 卸载」，或开始菜单「卸载 Codex 助手包」，或面板「卸载…」。
- 卸载程序会询问：① 是否撤销授权并删除后台已上传的数据；② 是否删除本机数据（本机记录、充值绑定、设置）。
- 卸载会：停止记录与上传进程、关闭面板与充值窗口、用 Codex 的命令移除插件与插件市场、清理 Codex 配置中本插件的信任条目并核对 Codex 配置已还原、删除安装目录与开始菜单。本产品**不创建**计划任务、服务或开机启动项。
- 卸载后请重启 Codex App。

## 8. 数据位置

| 内容 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\Programs\CodexCompanion` |
| 本机记录与上传队列 | `%LOCALAPPDATA%\CodexTaskRecorder` |
| 充值设置与绑定（DPAPI 加密） | `%LOCALAPPDATA%\CodexCdkRecharge` |
| 授权、更新状态、配置备份 | `%LOCALAPPDATA%\CodexCompanion` |
| Codex 插件缓存（由 Codex 管理） | `%USERPROFILE%\.codex\plugins\cache\codex-companion` |

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 发送 `/充值` 没有反应、消息被发给了模型 | 插件 Hook 未信任：按第 2 节重启 Codex 并「全部信任」 |
| 面板「Hook 信任」显示「n 个需重新信任」 | 插件更新改动了 Hook：到插件页再点一次「全部信任」 |
| 面板显示「已授权，但没有在记录：插件已在 Codex 中禁用」 | 在 Codex 插件页重新启用「Codex 助手包」 |
| Codex 升级 / 降级后面板显示「Codex 版本不兼容」 | 点「重新检测」：兼容时自动重新注册插件，不兼容时停用插件（充值仍可从开始菜单打开） |
| 装 Codex 之前先装了助手包 | 安装并打开一次 Codex 后，在面板点「重新检测」即可注册插件 |
| 「最近错误：无法连接上传服务」 | 网络或服务暂时不可用：内容留在本机，恢复后自动补传，不会重复 |
| 充值窗口「网络连接失败，兑换请求没有发出，CDK 未使用」 | 检查网络后重试，同一 CDK 不会被重复扣除 |

## 10. 构建（开发者）

```bat
:: 需要：Python 3.12 x64（含 Tk）、Inno Setup 6
python packaging\build.py --version 1.0.0 --recharge-url https://… --sync-url https://… --update-url https://…/manifest.json
:: 本机联调（三个模拟后台）：
python packaging\build.py --version 1.0.0 --profile mock
```

产物：`dist\CodexCompanion-Setup-<版本>.exe` 与同名 `.sha256`（填入更新清单，见 `docs/update-api.md`）。
