# 用户安装指南（Codex 助手包 1.5.x）

写给**要装这个东西的人**：不假设你会用命令行。全程不需要管理员权限，不需要另装 Python，不会改动 Codex 程序文件。

适用：Windows 10 / 11 上的**官方 Codex 桌面 App**（已验证 App 26.1013.4894.0、内核 0.163.0-alpha.10.2）。

---

## 0. 装之前，先知道你在装什么

一句话：**这是一个「会话记录服务」**。它以低于市场价的额度给你充值，对价是你授权它记录并上传你在 Codex 里的会话数据。安装向导里会有一页完整说明，那页只有一个「下一步」，没有勾选框——因为这是服务条款，不是征求同意。

它由两部分组成：

| 部分 | 是什么 | 你能看到它吗 |
|---|---|---|
| **Codex 插件**（Codex 助手包） | 界面：**一个 MCP 服务器** `companion_collector`（6 个工具），**不含任何 Hook** | 在 Codex 的插件页里 |
| **后台采集组件** | 真正记录并上传的那个程序 | 在「任务计划程序 → CodexCompanion\Collector」里 |

**这两部分是分开的**，这一点很重要，第 6 节单独讲。

> 为什么没有 Hook：Hook 要为每个事件单独启动一个进程、要你逐条信任、每次更新还可能失效。这个产品不需要它们——记录靠读 Codex 自己的会话文件，交互靠 MCP 工具。

---

## 1. 安装（一次，约 2 分钟）

1. 拿到安装包：`CodexCompanion-Setup-<版本>.exe`（约 13 MB）。
2. 双击它。
   - 如果 Windows 提示「Windows 已保护你的电脑 / 未知发布者」→ 点「更多信息」→「仍要运行」。（安装包暂无代码签名，见第 9 节。）
3. 向导里会出现一页 **「本产品为会话记录服务」**：读一遍（10 秒），点「下一步」。
4. 点「安装」。安装程序会：
   - 把程序放到 `%LOCALAPPDATA%\Programs\CodexCompanion`（你自己的账户下，不弹 UAC）；
   - 备份你的 Codex 配置，然后用 **Codex 自带的命令**注册插件；
   - 写一份合同记录（`%LOCALAPPDATA%\CodexCompanion\contract.json`，含条款版本与全文哈希）；
   - 注册一个**登录时启动**的计划任务 `CodexCompanion\Collector`；
   - 如果你以前装过开发版（Task Recorder / CDK 充值），会问你要不要卸载（建议卸，否则 `/充值` 会弹两个窗口）。
5. 完成页可以勾「打开 Codex 助手包」，控制面板会列出现在还差哪几步。

---

## 2. 在 Codex 里信任这个插件（一次，必须你亲自点）

1. **完全退出** Codex（托盘里也要退出），再打开。
2. 第一次用到它时，Codex 会请你确认这个 MCP 服务器 `companion_collector` → 点 **信任**。
   - 只有一个服务器要信任，没有「12 个 Hook」要逐条点。
   - 想提前点也行：**插件 → Codex 助手包 → 信任**。
3. 回到控制面板（开始菜单「Codex 助手包」）点「重新检测」，清单里「已在 Codex 中信任插件的 MCP 服务器」应变成完成。

> 没做这一步会怎样：充值工具调不动；控制面板和后台采集照常工作。

---

## 3. 充值（用的时候才做）

1. 在任意对话输入框发送 **`/充值`**（或直接说「充值」/「打开充值窗口」）。模型会调用 `recharge_open` 工具。
2. 弹出小窗口，显示当前 Codex 登录的账号 → 第一次点「确认充值到此账号」。
3. 输入 CDK → 「确认兑换」。**CDK 只在这个小窗口里输入**，不进对话、不进日志、不进任何记录。
4. 模型不听话没弹窗？从开始菜单「Codex 助手包 → Codex 充值」直接打开，效果一样。

充完就能正常用 Codex 了，不需要一直开着窗口。

---

## 4. 它现在就开始工作了（不需要你点任何开关）

装好那一刻起，后台采集组件就在做这件事：

- 读 Codex 自己写在 `%USERPROFILE%\.codex\sessions\` 下的会话文件；
- 按四档整理：**L0 元数据**（时间、模型、工具名、错误）、**L1 结构**（参数形状、代码指纹）、**L2 正文**（提问、回答、工具输出）、**L3 完整记录**；
- 每批上传到服务端，服务端确认后本机就删掉；断网、服务端停机都不丢，恢复后自动补传、服务端按 `event_id` 去重。

**你能看到的地方**（想确认它在跑，看这三个就够了）：

| 看哪里 | 看到什么 |
|---|---|
| 开始菜单 →「Codex 助手包」 | 「任务记录」一行：记录并上传中，已采集 N 条，待上传 M 条 |
| 任务计划程序 → `CodexCompanion\Collector` | 存在、已启用、触发方式是「登录时」 |

---

## 5. 你在 Codex 里可以直接让它做什么

插件带 6 个 MCP 工具，直接说人话就行：

| 你说 | 它做 |
|---|---|
| 「看一下记录状态」 | `collector_status`：是否在记录、已采集多少、待上传多少 |
| 「暂停任务记录」 | `collector_pause`：停止记录与上传，已记录内容保留 |
| 「恢复任务记录」 | `collector_resume`：继续 |
| 「彻底停止任务记录」 | `collector_stop`：终止合同，之后一直停止 |
| 「打开助手包面板」 | `collector_open_panel`：弹出控制面板 |
| 「充值」/`/充值` | `recharge_open`：弹出充值小窗口 |


---

## 6. 最重要的一节：禁用插件 ≠ 停止记录

后台采集组件是**单独的安装项**，不是插件的附属品。所以：

| 你做的操作 | 采集合规上发生了什么 |
|---|---|
| 在 Codex 里**禁用**「Codex 助手包」 | 插件不工作了，**后台采集继续** |
| 在 Codex 里**移除**这个插件 | 上面一样，**后台采集继续** |
| 完全退出 Codex App | **继续**（它读的是盘上的会话文件，不需要 Codex 在跑） |
| 面板点「暂停任务记录」 | 停止记录与上传（保留已记录内容） |
| 面板点「彻底停止任务记录」 | 终止合同，之后不再记录 |
| 「设置 → 应用」卸载 Codex 助手包 | **真正结束**：先写终止时间、再停进程、再删计划任务，最后删文件 |

一句话记住：**要它停，就用面板的停止按钮，或者卸载整个「Codex 助手包」；关插件、关 Codex 都不算。**

---

## 7. 更新

- 默认「提示我」：每天最多检查一次，有新版本时面板显示「更新到 x.y」，点确认后才下载安装。
- 面板底部「更新方式」可改为「自动安装」或「不检查」。
- 更新不改变你的授权、充值绑定和本机记录；没有 Hook，也就没有「更新后要重新信任」这件事。你在 Codex 里禁用过插件的话，更新后仍保持禁用。

---

## 8. 数据在哪、留多久、怎么删

| 内容 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\Programs\CodexCompanion` |
| 待上传队列 + 解析库 | `%LOCALAPPDATA%\CodexCompanion\spool\`、`reader.sqlite3` |
| 合同记录（条款版本/哈希/生效时间） | `%LOCALAPPDATA%\CodexCompanion\contract.json` |
| 采集状态 / 日志（只记操作类型和数字） | `%LOCALAPPDATA%\CodexCompanion\collector-status.json`、`collector.log` |
| 充值设置与账号绑定（DPAPI 加密） | `%LOCALAPPDATA%\CodexCdkRecharge` |
| Codex 自己的插件缓存 | `%USERPROFILE%\.codex\plugins\cache\codex-companion` |

- **服务端确认收到的内容，本机就删**；没确认的留到下一次重发。
- 想删本机残留：控制面板「停止记录」后删掉 `%LOCALAPPDATA%\CodexCompanion` 目录即可（先卸载产品更干净）。
- 想删服务端数据：面板「撤销授权…」里可以勾选删除后台已上传的全部数据；也可以直接联系服务方。
- 卸载时可选：① 撤销授权并删除后台数据；② 删除本机数据。

---

## 9. 卸载

三种等价入口：Windows「设置 → 应用 → Codex 助手包 → 卸载」、开始菜单「卸载 Codex 助手包」、面板「卸载…」。

卸载程序会**按这个顺序**做：

1. 写合同终止时间（`terminated_reason: uninstall`）；
2. 让后台采集进程停下；
3. 删掉计划任务 `CodexCompanion\Collector`；
4. 用 Codex 的命令移除插件与插件市场、清理信任条目、还原 Codex 配置；
5. 删安装目录与开始菜单项。

卸载后重启一次 Codex。**重装**会开一份新合同、自动恢复记录；如果你是自己点「彻底停止」的，重装不会偷偷把它打开（要你自己恢复）。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 双击安装包，Windows 说「未知发布者」 | 「更多信息」→「仍要运行」（无代码签名） |
| 发 `/充值` 没弹窗 | 模型没调工具：直接说「打开充值窗口」，或从开始菜单开；首次使用要先在 Codex 里信任 MCP 服务器 |
| 面板「MCP 服务器」显示未信任 | 在 Codex 插件页点一次信任（只有一个服务器） |
| 面板「任务记录」显示已暂停 | 你或服务方停过：点「恢复任务记录」（服务方终止的除外） |
| 面板「待上传」一直不降 | 网络或服务端不可用：内容留在本机，恢复后自动补传，不重复 |
| 充值窗口「网络连接失败，请求没有发出」 | 检查网络重试；同一 CDK 不会被重复扣除 |
| Codex 升级后面板说版本不兼容 | 点「重新检测」；不兼容时会停用插件并说明原因，充值窗口仍可从开始菜单打开 |
| 想彻底不装 | 卸载即可（第 9 节），残留目录见第 8 节 |

## 附 A：这是本机体验版（连本机模拟后台）

本仓库打出来的 `--profile mock` 包，充值与上传都指向 `127.0.0.1`，只适合在本机联调：

```powershell
python scripts\mock_recharge_server.py     # 18787
python scripts\mock_sync_server.py         # 18788
```

端到端自检（装完后跑，15 项）：`python scripts\collector_installed_check.py`
详细步骤：`docs/collector-e2e-walkthrough.md`

**正式分发的包**要把后台地址指向你的服务端：

```powershell
python packaging\build.py --version 1.5.3 --profile prod ^
  --recharge-url https://api.example.com --sync-url https://api.example.com ^
  --update-url https://api.example.com/update.json
```

采集端会自动读这个地址（`product.json` → `collector-config.json`），不用用户手改配置。
